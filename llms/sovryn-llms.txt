# Sovryn

> Sovryn is a Bitcoin-native, non-custodial decentralized finance (DeFi) protocol offering trading (spot, margin, perpetual swaps), 0% interest BTC-backed loans (Zero), the Sovryn Dollar (DLLR) Bitcoin-backed stablecoin, yield/liquidity pools, and SOV governance staking. Built on Rootstock (RSK) and incubator of BitcoinOS. Developer integration is via open-source smart contracts, subgraphs, an indexer HTTP API, and first-party JavaScript SDKs.
